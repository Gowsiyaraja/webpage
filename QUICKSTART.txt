🔌 API ENDPOINTS
====================================================================

Authentication:
  POST   /api/auth/register
  POST   /api/auth/login
  GET    /api/auth/me

Products:
  GET    /api/products          (searchable, filterable)
  GET    /api/products/:id
  POST   /api/products          (admin)
  PUT    /api/products/:id      (admin)
  DELETE /api/products/:id      (admin)

Orders:
  GET    /api/orders
  POST   /api/orders
  POST   /api/orders/create-payment-intent
  PUT    /api/orders/:id/status

Users:
  GET    /api/users/profile
  PUT    /api/users/profile
  GET    /api/users/wishlist
  POST   /api/users/wishlist/:productId
  DELETE /api/users/wishlist/:productId

Admin:
  GET    /api/admin/dashboard
  GET    /api/admin/analytics
  GET    /api/admin/users
  GET    /api/admin/orders

====================================================================
🌐 MONGODB ATLAS SETUP (Free)
====================================================================

1. Go to mongodb.com/cloud/atlas
2. Create free account
3. Create M0 (Free) cluster
4. Create database user with password
5. Whitelist your IP
6. Click "Connect" → Copy connection string
7. Replace <password> with your password
8. Add to backend/.env as MONGO_URI

Example:
  mongodb+srv://admin:mypassword123@cluster0.mongodb.net/blossom?retryWrites=true&w=majority

====================================================================
💳 STRIPE SETUP (Optional)
====================================================================

1. Go to stripe.com
2. Create account
3. Dashboard → API Keys
4. Copy Secret Key (starts with sk_test_)
5. Add to backend/.env as STRIPE_SECRET

❓ COMMON ISSUES & SOLUTIONS
====================================================================

Issue: "Cannot find module"
Solution: npm install in the respective folder

Issue: "MONGO_URI not set"
Solution: Create .env in backend/ with MongoDB connection string

Issue: "Connection refused"
Solution: Check backend is running on port 5000

Issue: "CORS error"
Solution: Verify CLIENT_URL in backend/.env matches frontend URL

Issue: "Port 5000/5173 already in use"
Solution: Kill process or change PORT in .env
